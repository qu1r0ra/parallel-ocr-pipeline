# Agent skills

### Agent documentation

- Apply the `asd-ste100` skill in STE-flavored mode when creating or editing agent-facing documentation.
- Write the human-facing `README.md` for readability. It is exempt from this skill requirement.

### Project verification

- For Python code changes, run `just verify` before PR delivery. This repository uses Python 3.15.
- This check supersedes the generic `Codes/AGENTS.md` exercise gate. See the `justfile` for recipe behavior.

### Issue tracker

- Track issues and specs in GitHub Issues. Read `docs/agents/issue-tracker.md` before tracker operations.

### Triage labels

- Use the default triage labels. Read `docs/agents/triage-labels.md` before assigning triage states.

### Domain docs

- For course requirements, read `docs/requirements.md` for MP1 or `docs/requirements-mp2.md` for MP2.
- For MP2 implementation or review, read `docs/agents/mp2-development.md` before applying MP1 concurrency or deployment guidance.
- Read `docs/agents/domain.md` before domain exploration.
