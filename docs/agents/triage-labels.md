# Triage labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation needed |
| needs-info | needs-info | More information needed |
| ready-for-agent | ready-for-agent | Specified for agent implementation |
| ready-for-human | ready-for-human | Human implementation or judgment needed |
| wontfix | wontfix | Will not be actioned |

Use this mapping whenever an engineering skill names a triage role.
